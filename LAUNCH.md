# Slop Detector Launch Post

## Primary Launch Post (X / Twitter)

Your timeline is drowning in synthetic engagement bait. Here is how we fixed it.

Introducing Slop Detector: a Chrome extension that scores every post on x.com in real time as you scroll.

Built with TypeSafe Jev, the System One decision model. Because Jev returns typed evaluations instead of generating text, each evaluation costs $0.000018 (0.0018 cents) and answers in 240 milliseconds.

How it works:
1. Score 80 and above: a compact crimson pill badge reading LIKELY AI SLOP with the confidence number.
2. Score 40 to 79: a subtle amber CHECK THIS outline around the card border.
3. Score under 40: completely untouched.

Our design rules:
- Additive only: posts are never hidden, collapsed, or deleted.
- We report confidence, never accusations. It says likely AI slop, never is AI generated.
- The API key stays strictly on your local relay. The browser never touches secrets.

100% open source. Check out the pull request and build your own:
https://github.com/jxspam/slop-detector/pull/4
