Slop Detector

Marks likely AI slop in the X feed as you scroll.

A Chrome extension powered by the TypeSafe Jev System One model. Each post is evaluated in real time for 0.0018 cents, placing confidence badges on synthetic content without touching genuine discussion.

Scoring and classification

The extension uses Jev to rate content against an ordered rubric. Scores are normalized to a 100 point confidence index.

01
Score 80 and above
Renders a compact crimson pill badge reading LIKELY AI SLOP followed by the score.
02
Score 40 to 79
Applies a subtle amber CHECK THIS outline around the card border without a verdict badge.
03
Score under 40
Left untouched. Authentic human conversation receives no badge or visual modification.

Installation and setup

Run the local relay server, then load the unpacked extension in Chrome or Edge.

git clone https://github.com/jxspam/slop-detector.git cd slop-detector export TYPESAFE_API_KEY=your_key_here node relay.js

Open edge://extensions or chrome://extensions, enable Developer Mode, and select Load Unpacked pointing to the extension directory.

Guarantees

Slop Detector reports model confidence. It does not enforce censorship.

  • Never removes, hides, collapses, or reorders feed content.
  • Says likely AI slop, never is AI generated.
  • Keeps your API key strictly on the local relay server, never in the browser.
  • Failed or rate limited calls leave the post completely untouched.
